 I have an idea that improves upon the blitzkrieg mod, but I know very very little about programming and statistics so don't think I will actually create this. 

  I think that having a mod that TELLS YOU TO DO SPECIFIC RUNS is a good concept, but found how the blitzkrieg mod does that kind of disappointing. I could see blitzkrieg being somewhat helpful because it cuts out your brain from the process of choosing which runs to do, which can stop you from doing things like forcing runs to 100 and losing out on overall consistency. However, I think what a mod like this should REALLY do is collect and analyze data as you play a level, using metrics such as passrate of an entire part from start to finish, passrate of a single chokepoint(which could be detected by the mod aswell), passrate of a part/chokepoint from 0, and passrate of a part/chokepoint when playing from a certain percent before that section in order to assign runs to the player based off what will increase your current probability of beating the level in any given attempt. You could even factor in the length of the level to assign runs that minimize how it will take to beat a level using sheer probability. And while you could totally argue that completing all the blitzkrieg runs after beating a level would be more efficient for improving as a player, I've found there is much more skill benefit to be found in learning and beating several new levels than there is in spending months on the same level. I've had the idea for a mod like this that mathematically optimizes your practicing for quite awhile now, I totally would create it if i knew enough about programming and statistics to do it.
